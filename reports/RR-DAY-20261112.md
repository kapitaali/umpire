while every decide failed with **connection refused** (the MCP proxies to `http://127.0.0.1:8081`,

`scripts/start-llama-server.sh`.

fails. `--status` and `--stop` are there too; `--stop` only ever signals the pid this script recorded,
after checking that process's command line is the pinned binary.

Every path was exercised: status → start (pins verified, ready in 2 s) → status → idempotent start →
stop → start again. The server is **left running** ✓, and the service chain was verified through the
MCP: health 200 and a real `decide` returning key `billing` with the calibration of record applied
(`cal-v1:057a5a35a9d4ec71`, calibrated confidence 0.855263) ✓. **U2/U6 are up again.**
