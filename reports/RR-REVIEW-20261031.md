## 3. Findings (all measured)

**F1 — `tests/` was ignored, and it holds gate artifacts.** `.gitignore:4` matched
`tests/`, which contains nine *tracked* replay-audit artifacts (`m3-replay-full`,
`m3-replay-quiescent`). Future tests or artifacts added there would silently never be
committed. Proof: `git check-ignore -v tests/.probe` → `.gitignore:4:tests/`.
**Fixed** in `d8ecef4` (line removed); `tests/` is trackable again.

**F2 — the `research/` ignore line matched nothing.** The line was
`research/   # internal planning documents, not for commit`; an inline `#` is not a
comment in `.gitignore`, so the whole string was a literal pattern. Proof:
`git check-ignore -v research/hermes-integration-plan.md` failed.
**Fixed** in `d8ecef4` (comment moved to its own line; the directory is now ignored).

**F3 — `.open-data-products/` is untracked and unignored.** SDK scratch
(`activity.log`) that shows up in every `git status`. ctxvm ignores the same path.
Not fixed — one line, no owner decision needed.

**F4 — 668 lines of integration sit outside version control.** `hermes/`:
`mcp_server.py` 261, `setup.sh` 155, `README.md` 89, `skill/SKILL.md` 163, plus
`config.yaml.example`. None of it is tracked, `README.md` never mentions hermes (0
matches), and no tracked test covers it. A clone cannot see that this capability exists.

**F5 — two MCP servers have drifted.** Root `mcp_server.py` is 522 lines and tracked;
`hermes/mcp_server.py` is 261 lines and untracked. Two implementations of the same
surface, one invisible to git.

**F6 — the installed skill copy is stale.** `~/.hermes/skills/umpire-hermes-integration/`
differs from `hermes/skill/SKILL.md` by 44 lines: the repo copy is the portable one
(`$UMPIRE_REPO`, `config.yaml.example`, `setup.sh` discovery), the installed copy still
carries `/home/theb/...` paths.

**F7 — the plan doc is stale about its own status.**
`research/hermes-integration-plan.md` says "Status: Planning phase (not yet implemented)"
while a 261-line MCP server exists. (Now ignored by F2's fix, so it is local-only; it
should either be corrected or deliberately kept out of the repo — pick one.)

**F8 — an uncommitted, correct cleanup.** `README-MCP.md` replaces hard-coded
`/home/theb/...` paths with `$UMPIRE_REPO` / `~` in 30 lines. It is a good change sitting
uncommitted; left alone in this card because it was already in flight and is unrelated to
the profile adoption.

**F9 — packaging does not pin fixture bytes (verified, not assumed).** After migrating
four fixtures, `grep -rn "ab-demo\|intent-router\|support-triage\|live-demo" odps/
contracts/ hub/` returned nothing, and `spec/build_hub.sh check` still reports the
regenerated hub byte-identical. So the migration could not invalidate the ODPS product,
the ODCS contract or the hub anchor.
