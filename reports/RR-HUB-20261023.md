## Build chain (`spec/build_hub.sh`, mirroring ctxvm `tools/build-hub.sh`)

1. Source gate: manifest re-validated by the open-data-products SDK.
2. Basename-staged copy → `odpc-build` → `catalog.yaml` + `index.html`
   (`productReferences=1, useCases=0, businessObjectives=0, signals=0`).
3. `$ref` rewritten hub-relative (`../odps/…`) — manifest not duplicated.
4. KPI injection (deterministic): rows parsed from `productStrategy`
   (`contributesToKPI` + `productKPIs`); current values derived from
   `calibration/umpire-cal-v2.json` + `corpus-v2.capture.meta.json`
   (ECE 2.67%, Brier 17.23%, accuracy 70.83%, page-table roundtrip 480/480
   0 re-decides → 100%, validator negatives 12/12 raw + 12/12 calibrated);
   honesty paragraph embedded ("declared gates, not model-performance promises").
5. Committed-catalog re-validation (`validate --json` → `valid:true`, `errors:[]`)
   + `odpc-summary`.
6. `check` mode: full rebuild to a temp dir, `cmp` against the committed files.
