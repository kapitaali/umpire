# RR-POLICY-20261116 — a destructive command may never target the home directory

Owner rule, standing, 2026-11-16: **never suggest, type, or endorse a recursive delete aimed at `~`,
`$HOME`, `/`, or any bare or computed path that could resolve to the home directory.** A cleanup names
the exact subdirectory; the home directory is never a target root. Non-negotiable.

## What landed

`AGENTS.md` §4 gains **law 9**. This repo had no statement of the rule: a grep for `recursive delete`
and for the command form across every tracked `.md` returned nothing but script usages.

The wording is this repo's own, not ctxvm's, because the traps differ:

| Trap here | In the law |
|---|---|
| the gate and the calibration checks run from the **repo root** | cleanup names the exact directory, never its parent |
| `calibration/` checksums are repo-root-relative; a stray file crashes the validator's glob | the named example is a repo-relative scratch dir (`<repo>/calibration/.scratch`), so "clean up the scratch" cannot become "clean up `calibration/`" |
| build and test stages leak `mktemp` dirs | stage dirs and temp venvs are named individually |
| `$VAR`-computed targets | stated: an unset `$VAR` makes a computed target a home delete |

## What was checked, not assumed

- **The three recursive deletes in tracked code are compliant**: `spec/build_hub.sh` deletes its own
  `$STAGE`/`$STAGE_OUT` through a `trap … EXIT`, and `tools/` holds no delete at all.
- **`runners/src/**` is not tracked** (`.gitignore:3` → `runners/`) and is the pinned llama.cpp source,
  local-only and hash-pinned. Its `git-bisect-run.sh` carries an unquoted `rm -rf ${dir}`; that is
  upstream code the gate does not run, and law 9 says so explicitly rather than inviting an edit to
  vendored bytes.
- No prompt file in this repo duplicates the rule, because there was none to begin with: `design/` holds
  `W9-TRANSFER.md` and one untracked note from another lane, and neither is an agent prompt. `AGENTS.md`
  is the entry document this repo's agents read first, so the law lives there and nowhere else.

## Verification

`bash tools/run-ci.sh` (offline, repo root) → `[umpire-ci] ALL GATES GREEN`, exit 0. Documentation only:
no script, no fixture, no calibration byte, no spec clause touched.
