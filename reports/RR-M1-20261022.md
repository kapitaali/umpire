## 3. Contract semantics honored live

- `key ∈ labels` by *decoding constraint* (GBNF literal alternates, quoted →
  JSON-valid guaranteed by the grammar, not hoped from the model).
- Raw (pre-calibration) probabilities harvested from the runner's per-token
  `top_logprobs` at the key choice point — **pre-mask distribution** renormalized over
  the requested labels (honest: raw model belief over the enum, not
  post-grammar-mass; documented + pinned in the `decoding` id).
- `confidence` = pinned entropy-complement formula (1 − H/log₂n) — measurement, not
  correctness (M2 replaces with corpus calibration).
- Re-decides priced exactly per M0: identical `(state, labels)` re-request →
  `page.fault source:"tool_recall"` naming the resident slot; no new declare.
  Cross-pin/seed divergence rules unchanged (A/B second-slot not exercised live yet —
  pin-B (Qwen2.5-1.5B) download deferred; noted next steps).

## 4. Found en route (validator-first + bisect earns keep — again)

- llama.cpp GBNF **rejects underscores in rule names** (`prob_key` → parse error;
  renamed `probkey`) — caught by server 400, bisected empirically.
- v0.7.0's logprobs shape = `token`/`logprob`/`top_logprobs` (not the old
  `tok_str`/`prob`/`completion_probabilities` `content`/`probs`); harness adapted.
- Quoted label literals required for JSON validity (Escaped via `\"…\"` inside GBNF
  literals; grammar source is assertion-tested by the live outputs).
- Live writer had to own the L3 `session.open` envelope (synthetic generator did; the
  writer didn't) — M0 validator caught it on the first live pair.
- GGUF: official repo ships only Q8_0 (1.88 GB, not q4) — Q8_0 taken; concurrently
  running resumable downloads corrupted a file twice mid-transfer (double-hash check
  exposed it) → single-writer download + stable double-hash before fill (lesson:
  never fill hashes from a partial file).

## 5. Honest limits

- **Latency:** ~10–13 s per decision on this 4-core CPU box (prompt eval ~0.9 s
  dominates after warm-up; Q8_0 weights). Outside the proposal's 100–600 ms honesty
  band — M1's goal is correctness+determinism, not serving throughput; the band
  returns with lower quantization, GPU runners, or serving infra (M3 decision).
- Probability attribution assumes label first-chars are pairwise distinct (M1
  boundary, warning emitted otherwise).
- q4/Qwen3-0.6B pin-B downloads not yet done — A/B second-slot rows remain
  exercised by M0 fixtures only.
- Determinism contract holds same-build/same-machine (P1 verified across restarts);
  cross-build byte-stability remains out of v0 scope (per spec).
